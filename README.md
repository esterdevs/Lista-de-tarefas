# 📝 Lista de Tarefas

Uma aplicação web de lista de tarefas desenvolvida para praticar HTML, CSS e JavaScript.

O projeto permite adicionar, concluir, desfazer e excluir tarefas, além de manter os dados salvos no navegador mesmo após atualizar ou fechar a página.

## 🚀 Funcionalidades

- ➕ Adicionar novas tarefas
- ✅ Marcar tarefas como concluídas
- ↩️ Desfazer tarefas concluídas
- 🗑️ Excluir tarefas
- 💾 Salvar tarefas automaticamente no navegador
- 📱 Interface responsiva para celular e tablet
- ✨ Animações e efeitos de interação

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📚 O que pratiquei neste projeto

Durante o desenvolvimento, pratiquei:

- Manipulação do DOM
- Funções em JavaScript
- Eventos e interações com botões
- Criação dinâmica de elementos HTML
- Uso do `localStorage`
- Responsividade com CSS
- Organização de arquivos
- Interface e experiência do usuário

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web e foi desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos em HTML, CSS e JavaScript.

## 📸 Demonstração

A aplicação permite criar uma lista de tarefas, marcar tarefas como concluídas e removê-las.
